# CodePulse — Intelligent Code Quality Analyzer

CodePulse is a web-based platform for analyzing Python source code, identifying code-quality issues, measuring complexity, and presenting actionable findings through an interactive dashboard.

## Planned Features

- Python source-code submission and validation
- Static analysis using Ruff and Pylint
- Complexity analysis using Radon
- Interactive code-quality dashboard
- Analysis history and report comparison
- GitHub repository integration
- Optional AI-powered explanations

## Technology Stack

- Frontend: React.js and Tailwind CSS
- Backend: Python and FastAPI
- Analysis: Ruff, Pylint, and Radon
- Database: PostgreSQL
- Testing: pytest
- Version Control: Git and GitHub
